# Webtoolkit Chrome Extension

A lightweight, multi-tool Chrome extension designed to provide essential web utilities and productivity tools directly in your browser.

## Overview

[Webtoolkit-Chrome-Extension](https://github.com/Soumyodipto68/Webtoolkit-Chrome-Extension) streamlines everyday developer and web browsing tasks by providing quick access to built-in tools without leaving your current tab.

## Key Features

* **CSS Picker:** Easily inspect, select, and capture CSS properties and styles from any element on a webpage.
* **Image Extractor:** Quickly locate and extract images embedded within active web pages.
* **Storage & Permission Management:** Configured to interact with browser storage for persisting user preferences and settings across sessions.

## Installation & Setup

1. **Clone the repository:**
```bash
git clone https://github.com/Soumyodipto68/Webtoolkit-Chrome-Extension.git
cd Webtoolkit-Chrome-Extension

```


2. **Install dependencies:**
```bash
npm install

```


3. **Build the extension:**
```bash
npm run build

```


4. **Load into Chrome:**
* Open Chrome and navigate to `chrome://extensions/`.
* Enable **Developer mode** in the top-right corner.
* Click **Load unpacked** and select the output `dist` folder generated by the build.
